Capítulo 3 Pruebas de hipótesis paramétricas y no paramétricas

Una vez finalizado el análisis exploratorio de los datos, se procede a plantear y resolver un conjunto de preguntas mediante pruebas de hipótesis, con el fin de confirmar de manera estadística algunos de los patrones observados previamente. El objetivo principal de esta sección es evaluar la relación entre las distintas variables del dataset y Premium Amount, verificando si las diferencias o asociaciones detectadas visualmente en el EDA son también estadísticamente significativas. Dado que en el EDA se evidenció que varias variables no presentan un comportamiento normal, se evaluará en cada caso si corresponde aplicar una prueba paramétrica o no paramétrica, según se cumplan o no los supuestos requeridos. Todas las pruebas se calculan con los 1,200,000 registros.

En las pruebas de correlación de Spearman se calcula además un intervalo de confianza para el coeficiente \(\rho\). Para ello se usa la transformación de Fisher con el error estándar de Bonett y Wright, donde \(r_s\) es el coeficiente de Spearman de la muestra y \(n\) el número de observaciones:

\[ z = \operatorname{arctanh}(r_s), \qquad EE = \sqrt{\frac{1 + r_s^2/2}{n - 3}}, \qquad IC_{95\%} = \tanh\left(z \pm z_{0.975}\,EE\right) \]

ICS <- list()

ic_spearman <- function(x, y, id, conf = 0.95) {
  n   <- length(x)
  rho <- cor(x, y, method = "spearman")
  ee  <- sqrt((1 + rho^2 / 2) / (n - 3))
  q   <- qnorm(1 - (1 - conf) / 2)
  lim <- tanh(atanh(rho) + c(-1, 1) * q * ee)
  S   <- (n^3 - n) * (1 - rho) / 6
  t   <- rho * sqrt((n - 2) / (1 - rho^2))
  p   <- 2 * pt(-abs(t), df = n - 2)
  ICS[[id]] <<- c(rho = rho, S = S, p = p, inferior = lim[1], superior = lim[2])
  data.frame(rho = rho, inferior = lim[1], superior = lim[2])
}

Pregunta 1: ¿Existe una diferencia significativa en el Premium Amount promedio entre clientes fumadores y no fumadores?

Sea \(\mu_1\) el promedio de Premium Amount para los clientes no fumadores, y \(\mu_2\) el promedio de Premium Amount para los clientes fumadores. Se plantea la siguiente hipótesis:

\[ \begin{aligned} H_0 &: \mu_1 = \mu_2 \quad \text{(no hay diferencia entre los grupos)} \\ H_1 &: \mu_1 \neq \mu_2 \quad \text{(existe una diferencia entre los grupos)} \end{aligned} \]

Para dar inicio al análisis, se separan los valores de Premium Amount en dos grupos según la variable Smoking Status, con el fin de trabajar con cada uno de forma independiente en las pruebas posteriores.

no_fumadores <- df %>% filter(Smoking_Status == "No") %>% pull(Premium_Amount)
fumadores <- df %>% filter(Smoking_Status == "Yes") %>% pull(Premium_Amount)

Antes de decidir qué tipo de prueba aplicar para comparar los dos grupos, es necesario verificar si la variable Premium Amount cumple con el supuesto de normalidad. Dado el gran tamaño de la muestra, se emplea la prueba de Lilliefors, que se aplica sobre la totalidad de las observaciones de cada grupo y permite empates.

library(nortest)
lillie.test(no_fumadores)

Con una confianza del 95%, la prueba de Lilliefors muestra que las distribuciones del Premium Amount para los clientes no fumadores (\(D = 0.11591\), p valor \(< 0.001\)) y fumadores (\(D = 0.11656\), p valor \(< 0.001\)) no provienen de una distribución normal, ya que en ambos casos el p valor es considerablemente menor al nivel de significancia establecido.

Dado que no se cumple el supuesto de normalidad en ninguno de los dos grupos, no es adecuado aplicar una prueba paramétrica (t-test) para comparar medias. En su lugar, se opta por una prueba no paramétrica que compara la tendencia central de las distribuciones. \[ \begin{aligned} H_0 &: \eta_1 = \eta_2 \\ H_1 &: \eta_1 \neq \eta_2 \end{aligned} \]

Entre los predictores se evaluaron 30 relaciones: 28 pares de variables numéricas con la correlación de Spearman y 2 pares de variables categóricas con la prueba chi-cuadrado (Preguntas 4 y 8), que no resultaron significativos. En conjunto, esto sugiere que ninguna característica individual del cliente, ni siquiera factores intuitivamente relevantes como fumar o el tipo de póliza, explica el monto de la prima en este dataset, lo cual podría deberse a que la relación real sea conjunta o no lineal, no capturable con pruebas univariadas. Como limitación, no se ajustó por comparaciones múltiples en las 48 pruebas, aunque esto no afecta la conclusión principal al basarse en el tamaño del efecto y no solo en el p valor. Por esta razón, en el Capítulo 4 se ajusta un modelo de regresión lineal múltiple que incorpora todos los predictores de forma simultánea, con el fin de evaluar si en conjunto logran explicar una proporción relevante de la variabilidad de Premium Amount.
